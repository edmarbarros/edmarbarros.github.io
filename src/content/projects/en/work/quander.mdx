## Problem

Hypesonic is Quander's AI growth platform. Its customers needed an in-product agent that answers from their real ad performance, ad data they can trust, a way to publish without leaving the product, and a way to pay for it. Meta was the first paid channel, and B2B customers were still billed manually.

## What I built

**The agent**

- **Observable.** Added Langfuse tracing for the Sonic in-product agent and moved its prompts into Langfuse, so runs could be inspected and prompts managed outside the code.
- **Sessions that survive.** Sessions recover after a reboot and rehydrate on cold start. I fixed retry, stale-response and attachment problems so the agent kept its context.
- **Tools.** The agent can read a user's Meta performance data, search TikTok ads live, and search ads by demographics and creative dimensions.
- **A sourcing agent.** An agent in the background workers collects ads into a global library. A declare-scope tool bounds what it collects. Media is re-hosted on S3 and analyzed with Gemini.
- **LLM-written reports.** The weekly performance report is narrated by an LLM through a provider abstraction, with a validator and prompts. Each result is saved with its validator warnings.
- **Metered usage.** Agent token use is priced and debited atomically, and shown in the credit history.

**Ad data and publishing**

- **Meta sync rebuilt.** A per-ad model cut Meta API cost about 25x. The sync adds daily demographics, runs that checkpoint and resume after a pause, deploy or crash, and an ETA that only falls.
- **Meta Ad Launcher.** A step-by-step wizard for batch publishing with multiple ad sets, copy variants, dynamic creative, publishing into existing campaigns, and fix-and-relaunch. It replaced the first launcher.
- **TikTok and Instagram.** The TikTok advertiser connection and ad sync landed behind a kill switch, and publishing to TikTok was in progress. Instagram-native creatives are ingested through the Instagram media object.

**Platform**

- **Self-serve billing.** Stripe subscriptions, a paywall with plan changes and past-due recovery, credit top-ups that expire, and storage limits driven by the plan.
- **Observability.** A shared logger and an OpenTelemetry bootstrap with trace propagation, and RED, LLM, ffmpeg and data-sync metrics. Also a shared PostHog package.
- **Video editor.** A video editor area with its editing engine as a workspace package, Whisper transcription, caption templates, brand-aware direction and cost telemetry.
- **Accounts.** An organization switcher, members and invites, and permission enforcement on content routes.

## Outcomes

- Opened a self-serve revenue stream. Before this, B2B customers were billed manually.
- Agent runs are traceable, and sessions survive reboots and cold starts.
- Meta API cost per sync is about 25x lower.
- Got hypesonic.com cleared from security vendor blocklists, which had been hurting traffic and signups.
- Designed, but did not implement, a Port, Adapter, Registry and Host architecture to make new ad integrations cheaper to add.
