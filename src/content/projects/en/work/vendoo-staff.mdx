## Problem

Vendoo's multichannel e-commerce platform processes 90k+ daily listings across a monolithic Node.js application with growing latency, tangled service boundaries, and rising infrastructure costs.

## What I built

- Designed and led the event-driven microservices migration on Kafka - service boundaries, data models, API contracts - reducing listing latency by 300ms.
- Took ownership of the GCP / Kubernetes infrastructure (Terraform + Helm): cluster provisioning, service-mesh configuration, environment-promotion workflows.
- Re-engineered the CI/CD pipelines (GitHub Actions and CircleCI), reducing Docker image sizes from 1 GB to 300 MB (70%) and cutting deployment cycle times.
- Implemented the observability stack for system health; proactively surfaced performance bottlenecks before user impact.
- Established internal "Tech Talks" and a 1:1 mentorship framework for the engineering org.

## Outcomes

- 41% reduction in monthly Elasticsearch spend via capacity planning; roadmap identified for a further 20% via index-lifecycle policies.
- 70% reduction in deployment artifact size (1 GB to 300 MB).
- 300ms reduction in listing latency.
